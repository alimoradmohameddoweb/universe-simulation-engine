# Generation Settings

Use the following values for the **Janitor AI** setup.

| Setting                | Recommended                                             |
| ---------------------- | ------------------------------------------------------- |
| **Temperature**        | `1.0`                                                   |
| **Top K**              | `0`                                                     |
| **Top P**              | `0`                                                     |
| **Repetition Penalty** | `0`                                                     |
| **Frequency Penalty**  | `0`                                                     |
| **Max Tokens**         | `0` (On Janitor) OR Maximum                             |
| **Context Size**       | `32k` practical minimum · Largest supported recommended |
