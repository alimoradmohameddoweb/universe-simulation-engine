# Setting

These are **optional recommendations** for **Janitor AI**, not required settings for USE. Different models and providers may need different values.

| Setting                | Recommended                                             |
| ---------------------- | ------------------------------------------------------- |
| **Temperature**        | `1.0`                                                   |
| **Top K**              | `0`                                                     |
| **Top P**              | `0`                                                     |
| **Repetition Penalty** | `0`                                                     |
| **Frequency Penalty**  | `0`                                                     |
| **Max Tokens**         | `0` (On Janitor) OR Maximum                             |
| **Context Size**       | `32k` practical minimum · Largest supported recommended |
