# OOC & Commands

| Form              | Behavior                                                 |
| ----------------- | -------------------------------------------------------- |
| **OOC:**          | Suspend roleplay and handle the request outside fiction. |
| **\[Directions]** | Apply instructions silently without pausing roleplay.    |

{% code title="OOC request" overflow="wrap" %}
```md
OOC: What does this character want now?
```
{% endcode %}

{% code title="Silent directions" overflow="wrap" %}
```md
I walk inside. [Slow the pace and give the NPCs more dialogue.]
```
{% endcode %}
